# Fret Finder

Build guitar fluency: hear notes, tunes and songs, then play them back on your guitar.

- **Notes:** hear a note, find it.
- **Echo:** hear a short tune, play it back. Tunes grow as you get them right.
- **Songs:** play songs you know from memory, either at your own pace or in time with a count-in.
- **Hum:** hum any tune, then play it on guitar.
- **Intervals:** find a second note from a reference note.

Plus neck areas that unlock as you improve, a speed goal, and a daily streak.

**Play it:** https://addisonbuhl.github.io/fret-finder/

It's a single `index.html` file with no build step. Anything pushed to `main` is live on GitHub Pages about a minute later. The mic needs https, which Pages already provides.
